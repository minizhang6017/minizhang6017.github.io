Settings

A role- and region-based profile system for different account types.

Product Management · Requirements · Systems Thinking · Cross-Functional Delivery

How can one profile system adapt to different users without exposing unnecessary complexity?

Owned the development of a role- and region-based profile settings feature designed to collect and manage user information across different account types.

01

Challenge

Profile requirements varied across user roles, organizational levels, and regions including Canada, the U.S., and APAC. The feature needed to provide each user with relevant information and access while supporting relationships between managers, team members, clients, and subaccounts.

02

My Role

  • Defined product requirements and user scenarios.
  • Mapped role-based profile and access needs.
  • Designed user flows and information structure.
  • Collaborated on data and system requirements.
  • Worked cross-functionally with UI/UX, frontend, and backend teams from definition through implementation.
03

Approach

I broke the problem down across three dimensions: user role, region, and organizational relationship.

From there, I identified which profile requirements could be shared across users and which needed to adapt based on context. I then translated those differences into structured product logic, user flows, and system requirements.

  • Separated shared and role-specific information requirements.
  • Mapped regional variations without creating disconnected experiences.
  • Considered how organizational relationships should affect visibility and access.
  • Aligned the frontend experience with backend data relationships.
  • Designed the feature as a flexible system that could support future expansion.
04

Product Considerations

Simple outside.
Flexible inside.

Scalability · Permissions · Regional Flexibility · Data Structure · Usability

The main product challenge was balancing complexity behind the scenes with a simple experience where users only encounter information relevant to their role and context.

05

Outcome

Created a more structured and scalable profile framework that could support multiple user types, regional requirements, and organizational relationships within a unified experience.
